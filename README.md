# המשחקים של עמית 🎮

פלטפורמת משחקים פשוטה לילדים (בעברית), עובדת גם בלי אינטרנט (PWA).

## המשחקים

1. **משחק זיכרון** – בוחרים 4–20 זוגות ונושא לתמונות: חיות, משחקי גן ופעילויות בחוץ, אוכל, גיבורי על (תמונות מ-`images/superheros/`), צבעים.
2. **ספירה והתאמה** – בכל סבב מופיע כרטיס עם 1–10 חיות מאותו סוג. סופרים וגוררים (או נוגעים) במספר הנכון. אפשר לבחור לפני המשחק את המספר המקסימלי (2–10). 10 סבבים לכל משחק.

כפתור הרמקול למעלה משתיק/מפעיל צלילים והקראת מספרים בעברית.

## איך מריצים

זה אתר סטטי – צריך להגיש אותו משרת (בגלל ES modules ו-Service Worker). לא לפתוח את `index.html` ישירות מהדיסק.

מקומית:

```bash
cd "~/Documents/my apps/Amit Games" && python3 -m http.server 8777
```

ואז לפתוח http://localhost:8777

## התקנה על אייפד / טלפון

1. להעלות את התיקייה לאירוח סטטי כלשהו (Netlify / GitHub Pages / Cloudflare Pages – פשוט לגרור את התיקייה).
2. לפתוח את הכתובת ב-Safari → כפתור השיתוף → "הוסף למסך הבית".
3. עכשיו זה נפתח כמו אפליקציה במסך מלא, וגם עובד בלי אינטרנט.

## מבנה

```
index.html            – נקודת כניסה
manifest.webmanifest  – הגדרות PWA
sw.js                 – מטמון לעבודה לא מקוונת (יש לעדכן את CACHE בכל שינוי)
css/styles.css
js/app.js             – מסך הבית והניווט
js/games/memory.js    – משחק הזיכרון
js/games/counting.js  – משחק הספירה
js/data.js            – רשימות התמונות/החיות והמילים בעברית
js/audio.js           – צלילים + דיבור
js/grid.js            – חישוב פריסת הלוח שתתאים למסך
vendor/               – React + htm (מקומי, בלי שלב build)
icons/                – אייקונים
```

## שינויים נפוצים

- להוסיף תמונות למשחק הזיכרון: `js/data.js` → `MEMORY_SUBJECTS`. לגיבורי על – לשים את הקובץ ב-`images/superheros/`, להוסיף את שמו לרשימה, ולהוסיף אותו גם ל-`ASSETS` ב-`sw.js`.
- להוסיף חיות למשחק הספירה: `js/data.js` → `COUNT_CRITTERS`.
- לשנות טווח זוגות: `MIN_PAIRS` / `MAX_PAIRS` ב-`js/games/memory.js`.
- לשנות מספר סבבים בספירה: `ROUNDS` ב-`js/games/counting.js`.
- **חשוב:** אחרי כל שינוי בקבצים, לעדכן את המספר ב-`const CACHE = "amit-games-v1"` בקובץ `sw.js` כדי שהגרסה החדשה תיטען.
